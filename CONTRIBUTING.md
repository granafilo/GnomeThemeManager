# Contribuire a GNOME Theme Manager

Grazie per l'interesse a contribuire a GNOME Theme Manager!

## Linee guida per lo sviluppo

1. **Codice pulito**: Segui lo standard PEP 8. Usiamo Ruff per il controllo dello stile e la formattazione.
2. **Test**: Aggiungi test unitari o di integrazione per ogni nuova funzionalità o bug fix.
3. **Commit messaggi**: Consigliamo l'uso di messaggi di commit convenzionali (Conventional Commits).
