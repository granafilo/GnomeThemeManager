# Contributing to GNOME Theme Manager

Thank you for your interest in contributing to GNOME Theme Manager!

## Development Guidelines

1. **Clean Code**: Follow PEP 8 standards. We use Ruff for code style checks and formatting.
2. **Testing**: Add unit or integration tests for every new feature or bug fix.
3. **Commit Messages**: We follow Conventional Commits guidelines.
